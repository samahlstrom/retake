# The sample project

A 22-second how-to video ("How to brew pour-over coffee") in versions v1 and v2, made from a timeline, plus what it
takes to try the whole review loop without a camera or a microphone. The walkthrough is in
[`docs/quickstart.md`](../../docs/quickstart.md).

Nothing in it is a recording. The footage is ffmpeg's test patterns, the titles are drawn by `retake-edit`, and both
voices are synthetic.

## Make it

```bash
scripts/make-sample.sh ~/retake-sample              # v1 and v2, rendered from timeline.json
scripts/make-sample.sh ~/retake-sample --with-take  # the same, plus a review take on v2 (instead of recording one)
```

It needs ffmpeg and `retake-edit`. The videos are rendered on your machine, so they aren't in the repository.

| Path in the sample folder | What it is |
|---|---|
| `how-to/v1/how-to_v1.mp4` | Timeline revision 0. |
| `how-to/v2/how-to_v2.mp4` | After `patches/01-v2.json`: a warmer title card, and the "20 g" pop moved to the word "grams". |
| `how-to/v2/how-to_v2.review/2026-01-15_10-00-00/` | With `--with-take`: the pre-made take. |
| `edit/` | The editor project: `timeline.json`, `patches/`, `voice/` and the generated `media/`. |

## What's here

| File | What it is |
|---|---|
| `timeline.json` | The edit as data (`spec/timeline.md`): a title card, three steps on test footage with labels, an outro. |
| `patches/01-v2.json` | Revision 0 → 1: v2. |
| `patches/02-v3.json` | Revision 1 → 2: what an agent would write to answer the take's note. The quickstart uses it when no agent is at hand. |
| `voice/vo.ogg` | The voice-over: five phrases, one per spine item. |
| `voice/vo.words.json` | Its words with times, which the timeline's `word:` anchors resolve against. |
| `voice/phrases.json` | Each phrase's text, start and end in `vo.ogg`. |
| `take/` | The pre-made take on v2, as the review page saves one (`spec/take-format.md`). At 0:11.0 the reviewer says "The labels at the bottom are too small. Make them bigger, please." and loops the step label in red. `transcript.json` is included, so the notes build even where transcription isn't set up. |
| `make-voice.sh` | Regenerates `voice/` and the take's audio and transcript. |
| `make-take.mjs` | Regenerates the take's JSON files. |
| `run-quickstart.sh` | Runs the quickstart without a person, as a smoke test. |

## How it was made

- **Speech.** [eSpeak NG](https://github.com/espeak-ng/espeak-ng) 1.52.0, a formant synthesizer: the voice is
  computed from rules, not from anyone's recordings, and no MBROLA voices were used. The voice-over is `en-us+m3`
  and the reviewer is `en-us+f3`, at 150 words per minute.
- **Word times.** `retake transcribe` (whisper.cpp). The model hears "pour-over" as "porover", "ground" as "browned"
  and the numbers as digits; the timeline only anchors on words it heard right.
- **Footage.** ffmpeg's `testsrc2`, `testsrc` and `life` sources, generated by `scripts/make-sample.sh`.
- **Text.** Baloo 2 (SIL Open Font License), the font built into `retake-edit`.

To change the speech, edit the phrases in `make-voice.sh`, run it (it needs espeak-ng, ffmpeg with libopus and a
`retake` with transcription set up), then fix any spine `in`/`out` and `word:` anchors in `timeline.json` that moved.
