# Contributing

- Read `CLAUDE.md` (also linked as `AGENTS.md`). The rules there apply to people and AI agents alike.
- Change the spec in `spec/` before changing behavior it describes.
- `make test lint e2e` must pass before a change lands. CI runs the same.
- Test media is generated or CC0. Never commit real footage, voices, or assets with unclear licenses.
- Keep the review UX minimal: R to record, pen only while recording, no extra chrome.
